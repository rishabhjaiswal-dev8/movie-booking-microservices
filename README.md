# Movie Booking Microservices

Microservices based Movie Booking Backend - Spring Boot + Eureka

### Services
- **eureka-server (8761)** - Service Registry
- **movies-api (8081)** - Movies, Shows
- **users-api (8082) - Users & Bookings

### Tech
Java 21, Spring Boot, Spring Cloud Eureka, Maven, MySQL

### How to Run
1. Run eureka-server first - http://localhost:8761
2. Then run movies-api
3. Then run users-api

cd eureka-server
./mvnw spring-boot:run
